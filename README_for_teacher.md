# First Python plotting exercise

## Recommended student workflow

1. Open the course JupyterLite link in a browser.
2. Upload the notebook and Excel file using the file-browser upload button.
3. Run cells from top to bottom with Shift+Enter.
4. Save/download the completed notebook as evidence of the work.

## Why this is a good first exercise

- Students work with a familiar Excel file while learning a new analysis environment.
- Each code cell is short and produces an immediate visual result.
- The questions emphasise graph choice and interpretation rather than syntax.
- The same workflow will transfer to later calcium-imaging, electrophysiology, and sleep-EEG exercises.

## Suggested 50-minute structure

- 5 min: demonstrate opening JupyterLite and uploading files.
- 10 min: run the import, loading, and inspection cells.
- 20 min: students create and annotate the three plots.
- 10 min: groups compare which graph answers each question best.
- 5 min: save the notebook and complete the final reflection.

## Teaching notes

Do not require students to install Python, VS Code, or GitHub Desktop for this first activity. Use VS Code to edit the notebook if convenient, and use GitHub as the distribution/version-control location. Students only need the JupyterLite webpage and the two supplied files.

The dataset is synthetic and intended to teach plotting, not support a biological conclusion. Tell students explicitly that a graph can be technically correct but still poorly matched to the question.
